Minory Investments


Question1. Website Creation
I created a website for Minory Investments LTD, an automotive accessories business. The website provides information about automotive accessories such as tires, wheels, rims, lights, interior materials, interior colours, infotainment systems, door panels, door handles, strobe lights, and exhaust pipes. It also contains links to third-party dealers, a car library, and a gallery of previously completed projects. The website also provides the company's location and contact information.    
Question2. HTML Elements

The five elements I found most challenging were:
<nav> – I used navigation sections to organize links to different pages such as Tires, Wheels, Rims and Lights.
<a> – I used anchor elements to connect the homepage to different pages and sections of the website.
<section> – I used sections to divide the website content into different categories, such as automotive accessories and interior components.
<main> – I used the main element to contain the main content of the website.
<header> – I used the header element to contain the title of the website.    
These elements required careful organization because they determine how the different parts of the website are show & are connected.
2. How did you use semantic elements like <section>, <article>, <header>, and <footer>?
I used semantic elements to organize the website. The <header> contains the website title, while <main> contains the main website content. I used <section> to show the different  automotive accessories & car dealing option. The <footer> has a thank-you message for visitors.        
The HTML file does not contain an <article> element, so I cannot claim that I used one.
3. Which element was most useful for organizing your layout and why?
The <section> element was most useful for organizing the content because it allowed me to divide the website into separate areas, one section contains automotive accessories while another contains interior components as examples.
